## Rules

- Write the ADR at the time of the decision, not retroactively.
- Don't edit a merged ADR. To revise, write a new one and mark the old one `Superseded by ADR-NNNN`.
- Number sequentially. Filenames: `NNNN-kebab-case-title.md`.
- Keep them short — one screen of reading, ideally. Detail belongs in implementation docs.
